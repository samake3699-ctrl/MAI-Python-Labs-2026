# Использование искусственного интеллекта — лабораторная работа № 2

**Траектория:** Python Core · **Инструмент:** ChatGPT (OpenAI) · **Период:** октябрь 2026 г.

## Для чего использовался ИИ

ChatGPT использовался как **вспомогательный инструмент** для:

- перевода условий задания с русского на французский и объяснения технических понятий;
- планирования модулей потоковой обработки и анализа сходства;
- подготовки и обсуждения кода для `tokenize`, 3-грамм, Жаккара и AST;
- создания предложений по тестам, синтетическому корпусу, настройке порогов и анализу ошибок;
- подготовки экспериментов с `cProfile`, `tracemalloc` и повторяемыми измерениями;
- обсуждения оптимизации с предварительным вычислением признаков эталона;
- подготовки версии конфигурации разрешённого шаблона и русскоязычной документации.

Значительная часть исходного кода и тестов была предложена с помощью ChatGPT. Это использование указывается открыто и не представляется как полностью самостоятельное написание каждого фрагмента.

## Как проверялись предложения

Программы и тесты запускались в локальном Python-окружении с использованием `unittest`. Также были самостоятельно выполнены команды генерации корпуса, оценки качества, анализа ошибок, измерения производительности и смены конфигурации. Подтверждённый в переписке запуск полного набора ранее завершился `Ran 98 tests ... OK`; окончательный набор после последующих дополнений следует перепроверить перед сдачей.

Выводы о качестве сделаны только для **синтетического учебного корпуса**; генеративный ИИ не использовался как судья, принимающий решения о плагиате.

## Роль ИИ в приложении

Само приложение **не обращается к API ChatGPT** и не выполняет генеративное определение авторства. Сравнение выполняется детерминированными алгоритмами Token/Jaccard и AST. Метка `review_required` — рекомендация к ручной проверке, а не основание для санкций.

## Ответственность и ограничения

Сгенерированный код требует проверки и понимания разработчиком. Результаты на малом корпусе нельзя обобщать на реальные академические работы. При защите необходимо уметь объяснить основные функции, методы, результаты и ограничения без опоры на выводы ИИ.
