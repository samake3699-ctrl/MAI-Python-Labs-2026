# AI_USAGE.md

## Использование искусственного интеллекта при выполнении лабораторной работы № 1

**Лабораторная работа:** Приём работ и расширяемые анализаторы  
**Траектория:** Python Core  
**Использованный инструмент:** ChatGPT (OpenAI)

### 1. Цели использования ИИ

При выполнении лабораторной работы использовался ChatGPT в качестве вспомогательного инструмента для изучения требований, проектирования архитектуры, разработки и проверки программного кода.

Поскольку задание предоставлено на русском языке, ИИ также использовался для перевода и объяснения технических требований на французском языке.

### 2. Основные направления помощи

ChatGPT использовался для следующих задач:

- перевод и объяснение условий лабораторной работы;
- обсуждение структуры Python-пакета в формате `src-layout`;
- объяснение `dataclass`, `Protocol`, композиции и реестра фабрик;
- помощь в реализации моделей данных, парсера JSONL и валидации;
- помощь в реализации обнаружения дубликатов и конфликтов;
- помощь в разработке анализаторов `LengthAnalyzer` и `TemplateAnalyzer`;
- помощь в написании и исправлении автоматических тестов;
- объяснение ошибок Python и результатов выполнения команд;
- подготовка технической документации.

### 3. Проверка результатов

Предложенные решения проверялись посредством запуска программы и автоматических тестов в локальном окружении.

Последний запуск тестов:

```text
python -m unittest discover -s tests -v

Ran 20 tests in 0.049s

OK
```

Успешное прохождение тестов подтверждает выполнение проверяемых сценариев, но не гарантирует отсутствие всех возможных ошибок.

### 4. Использование ИИ внутри приложения

Разработанное приложение не использует внешние языковые модели, API генеративного ИИ или машинное обучение.

Анализаторы выполняют детерминированные операции:

- подсчёт непустых строк текста и кода;
- поиск точных совпадений с разрешёнными шаблонами.

Приложение не выполняет загруженный код студентов и не использует декларацию ИИ для автоматического определения авторства работы.

### 5. Ограничения и ответственность

Ответы и предложения ИИ рассматривались как вспомогательные материалы и проверялись в процессе разработки.

Использование ChatGPT не заменяет необходимости понимать архитектуру проекта, уметь объяснять программный код и самостоятельно демонстрировать работу приложения на защите.

### 6. Заключение

ChatGPT использовался для образовательной, технической и документационной поддержки при выполнении лабораторной работы. Использование инструмента указано открыто.
